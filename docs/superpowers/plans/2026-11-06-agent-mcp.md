# Agent MCP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. The user authorized specification and implementation together; proceed within that scope and obtain fresh review before claiming completion.

**Goal:** Connect agents to Alcove over authenticated MCP to manage notes and schedule calls.

**Architecture:** Add account-owned delegated grants and a dedicated stateless MCP boundary, preserving browser auth and the domain modules' authorization. Add OAuth consent and personal-token management to the existing app.

**Tech Stack:** Existing pnpm/TypeScript/Hono/React/Postgres; official `@modelcontextprotocol/server` and `@modelcontextprotocol/client` 2.4.0.

**Spec:** `docs/superpowers/specs/2026-11-06-agent-mcp-design.md`.

## Global constraints

- Strict TS: no any, casts, non-null assertions or suppressions; never weaken checks.
- Real HTTP integration tests with real Postgres/object storage only. No browser/component/unit tests.
- Forward-only additive migration after 0016; seal new readable metadata with location-bound headers.
- Reuse existing note/meeting permissions; no owner ID in tool input; no credentials/content in logs or URLs.
- Existing app API/query/UI boundaries and light/dark/narrow layouts remain in force.

## Review focus

- A consent request resumed after Google sign-in must return to the same valid request, without an open redirect.
- A stolen/replayed refresh token must revoke its grant across instances; ordinary browser sessions are independent.
- A retry after a disconnect/crash must not silently schedule another call; duplicate operation IDs with different bodies conflict.
- A shared note's access or transcript retention changed after delegation must take effect on the next tool call.
- Account deletion/expiry must remove stored credentials, encrypted metadata and operation receipts without touching other accounts.
